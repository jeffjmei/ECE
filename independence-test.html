8  Independence Test

8.1 Classical Theory

For jointly Gaussian \((X, Y)\), zero correlation and independence are equivalent, so testing \(H_0: \rho = 0\) is also a test of \(H_0: X \perp Y\). The statistic \(T = \sqrt{n-2}\,\hat\rho / \sqrt{1 - \hat\rho^2}\) follows an exact \(t_{n-2}\) null distribution.

Without the Gaussian assumption, \(\rho = 0\) no longer implies independence — for example, \(X \sim N(0,1)\) and \(Y = X^2\) satisfy \(\operatorname{Cov}(X, Y) = 0\) but \(X \not\perp Y\). Two approaches handle the non-Gaussian case:

  • Permutation test. Permuting \(Y\) breaks any dependence on \(X\) while preserving marginals, giving an exact test of \(H_0: X \perp Y\) under any distribution.
  • Asymptotic test of independence. Under \(H_0: X \perp Y\), the errors are independent, so \(\kappa_{22} = 1\) and \(\sqrt{n}\,\hat\rho \xrightarrow{d} N(0, 1)\).

For the weaker null \(H_0: \rho = 0\) without assuming independence, \(\kappa_{22}\) need not equal 1, and the asymptotic variance is \[ v^2 = \frac{1}{n} \left(\omega_x^2 + \omega_y^2 + \kappa_{22} + \frac{5}{2}\right). \] A robust test plugs in \(\hat\kappa_{22}\).

8.2 Estimating \(\kappa_{22}\) via \(V\)

Let \(s_i^{(k)} = (X_i - X_{i+k})(Y_i - Y_{i+k})\) and \(S_i = s_i^{(1)} + s_{i+1}^{(1)} - s_i^{(2)}\) as in the Multiplier Bootstrap chapter, so that \[ \bar{S} = \frac{1}{n}\sum_{i=1}^n S_i = \frac{2T_1(X,Y) - T_2(X,Y)}{n} \] is twice the ECE covariance estimator. Define the lag-2 variance estimate \[ V := \widehat{\operatorname{Var}}(\bar{S}) = \frac{1}{n^2}\!\left(\sum_{i=1}^n S_i^2 + \sum_{i=1}^n (S_i S_{i+1} + S_{i+1} S_i) + \sum_{i=1}^n (S_i S_{i+2} + S_{i+2} S_i)\right). \]

Since \(\bar S = (2T_1 - T_2)/n\), we have \(V \approx \operatorname{Var}(2T_1 - T_2)/n^2\). Under \(H_0\) (\(\sigma_{xy} = 0\)), the variance on the right has a closed form in \(\kappa_{22}\), so we can solve for \(\kappa_{22}\) from \(V\).

Derivation: \(\operatorname{Var}(2T_1 - T_2)\) from \(\Sigma_Z\)

Under \(H_0\) (\(\sigma_{xy} = 0\)), \[ \operatorname{Var}(2T_1 - T_2) = 4[\Sigma_Z]_{55} - 4[\Sigma_Z]_{56} + [\Sigma_Z]_{66}. \] Plugging in the \(\Sigma_Z\) entries from the Z-Test chapter, \[[\Sigma_Z]_{55} = 2n\sigma_x^2\sigma_y^2(2\kappa_{22}+1) + 2n\sigma_y^2\omega_x^2 + 2n\sigma_x^2\omega_y^2,\] \[[\Sigma_Z]_{56} = 4n\sigma_x^2\sigma_y^2\kappa_{22} + 2n\sigma_y^2\omega_x^2 + 2n\sigma_x^2\omega_y^2,\] \[[\Sigma_Z]_{66} = 2n\sigma_x^2\sigma_y^2(2\kappa_{22}+1) + 4n\sigma_y^2\omega_x^2 + 4n\sigma_x^2\omega_y^2,\] and simplifying, \[\operatorname{Var}(2T_1 - T_2) = 2n\bigl[(2\kappa_{22}+5)\sigma_x^2\sigma_y^2 + 2\sigma_y^2\omega_x^2 + 2\sigma_x^2\omega_y^2\bigr]. \qquad\square\]

Since \(nV \approx \operatorname{Var}(2T_1-T_2)/n\), substituting and solving gives \[\hat\kappa_{22} = \frac{nV}{4\hat\sigma_x^2\hat\sigma_y^2} - \frac{\hat\omega_x^2}{\hat\sigma_x^2} - \frac{\hat\omega_y^2}{\hat\sigma_y^2} - \frac{5}{2}.\]

8.2.1 Simulation: Does \(\hat\kappa_{22}\) Recover the Truth?

To check the formula for \(\hat\kappa_{22}\), we simulate 1000 datasets and compare the distribution of \(\hat\kappa_{22}\) to the true value. If the formula is correct, the sample mean (dashed line) should be close to the true value (red line). We consider three cases: independent errors (\(\kappa_{22} = 1\)), a strongly dependent case (\(\kappa_{22} = 5\)), and a one-parameter family interpolating between the two.

  • Independent (\(\kappa_{22} = 1\))
  • Dependent (\(\kappa_{22} = 5\))
  • \(\lambda\)-Mixing

Using \(\varepsilon_y = \lambda(\varepsilon_x^2-1)/\sqrt{2} + \sqrt{1-\lambda^2}\,\eta\) with \(\varepsilon_x, \eta \stackrel{iid}{\sim} N(0,1)\), which gives \(\sigma_{xy} = 0\) and \(\kappa_{22} = 1 + 4\lambda^2\).
