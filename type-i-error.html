11.3 \(p = 2\): Dependence Testing (Quadratic)

Correlation dependence testing are closely related but subtly different. In the classical Pearson test, interpretation is dependent on on the assumptions made.

Consider this canonical example: \[ \varepsilon_y = \frac{\varepsilon_x^2 - 1}{\sqrt{2}}, \quad \varepsilon_x \sim N(0, 1). \] Clearly, \(\varepsilon_x\) and \(\varepsilon_y\) are dependent, but by construction \(\operatorname{Cor}(\varepsilon_x, \varepsilon_y) = 0\). Specifically, \(\kappa_{22} = 5\).

Therefore, a dependence test will identify dependence between \(\varepsilon_x\) and \(\varepsilon_y\), but a correlation test will not.

11.4 \(p = 2:\) Dependence Testing (\(\kappa_{22} = 0.5\))

The case \(\kappa_{22} < 1\) is a bit unnatural. For bivariate Gaussian errors, \[\kappa_{22} = 1 + 2\rho^2 \geq 1 \text{ for all } \rho \in [-1, 1],\] so the Gaussian family can never produce it.

Since \[\kappa_{22} = 1 + \frac{\operatorname{Cov}(\varepsilon_x^2, \varepsilon_y^2)}{\sigma_x^2 \sigma_y^2},\] having \(\kappa_{22} < 1\) requires \(\operatorname{Cov}(\varepsilon_x^2, \varepsilon_y^2) < 0\): large squared values of one component must tend to coincide with small squared values of the other.

The circular distribution provides a concrete construction: \[ U \sim \mathrm{Uniform}(0, 2\pi), \quad \varepsilon_x = \sqrt{2}\cos(U), \quad \varepsilon_y = \sqrt{2}\sin(U). \] Because \(\varepsilon_x^2 + \varepsilon_y^2 = 2\) almost surely, whenever \(\varepsilon_x^2\) is large \(\varepsilon_y^2\) must be small, giving exactly the required negative covariance: \(\operatorname{Cov}(\varepsilon_x^2, \varepsilon_y^2) = \mathbb{E}[\sin^2(2U)] - 1 = \tfrac{1}{2} - 1 = -\tfrac{1}{2}\). With \(\sigma_x^2 = \sigma_y^2 = 1\), this yields \(\kappa_{22} = 0.5\).

At the same time, \(\operatorname{Cov}(\varepsilon_x, \varepsilon_y) = \mathbb{E}[\sin(2U)] = 0\), so the errors are uncorrelated and a Pearson correlation test has no power — yet the pair is strongly dependent.

11.9.3 Mechanism: Not in Asymptotic CLT Regime

The u-shaped p-curves indicate that there are insufficient small and large p-values. This means the distribution of bootstrap statistics has less variance than the true distribution.

To see why, we compare the distribution of the test statistic \(Q = \max_j |\bar S_j|\) under two distributions. The true distribution is obtained by repeatedly drawing a fresh dataset and computing \(Q\) from the observed \(\bar S\). The bootstrap distribution is obtained by drawing a single dataset, estimating the covariance \(W\) of \(\bar S\) from that dataset, and then drawing one bootstrap replicate \(Q^* = \max_j |Z_j|\) with \(Z \sim N(0, W)\). When \(n\) is small relative to \(p\), \(W\) underestimates the true variance of \(\bar S\), so the bootstrap distribution is too narrow and the test is conservative.

The plots below also include four related distributions:

  • True: the actual distribution of the test statistic, obtained by repeatedly generating a fresh dataset and computing \(Q\) directly, with no covariance estimation involved — this is the ground truth the others are compared against.
  • Bootstrap: for each simulated dataset, we estimate \(W\) from that dataset and draw a single bootstrap replicate \(Q^*\) from \(N(0, W)\). This differs from how the bootstrap is used in practice, where we would draw many replicates from the same estimated \(W\) to build a reference distribution for a single dataset’s test; here we draw only one replicate per dataset so that repeating this many times traces out the bootstrap’s overall sampling distribution.
  • Bootstrap (Oracle): replaces the single-sample estimate of \(W\) with its true value (found by averaging over many datasets), isolating whether the conservativeness comes from estimating \(W\) or is inherent to the method.
  • Naive Bootstrap: estimates \(W\) using the ordinary sample covariance, which is only valid when there are no change points; it serves as a benchmark for the upper bound on performance.
  • Naive Bootstrap (Oracle): the oracle version of the naive estimate.

Observations:

  • The Bootstrap distribution has more spread than the True distribution, so we expect small p-values to be under-represented.
  • The Bootstrap (Oracle) distribution has less spread than the True distribution, so we expect small p-values to be over-represented.
  • Naive Bootstrap and Naive Bootstrap (Oracle) exhibit similar patterns, but to a less severe degree.
