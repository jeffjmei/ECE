A.2 SVD for Identifying the Null Space

Given the constraint matrix \(G \in \mathbb{R}^{m \times n}\), the singular value decomposition is: \[G = U \Sigma V^T\] where \(U \in \mathbb{R}^{m \times m}\) and \(V \in \mathbb{R}^{n \times n}\) are orthogonal matrices, and \(\Sigma\) is a diagonal matrix with singular values \(\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_{\min(m,n)} \geq 0\).

A.2.1 Connection to the Null Space

The null space of \(G\) is: \[\text{null}(G) = \{a \in \mathbb{R}^n : Ga = 0\}\]

If \(G\) has rank \(r < n\), the right singular vectors corresponding to zero singular values span the null space: \[\text{null}(G) = \text{span}\{v_{r+1}, v_{r+2}, \ldots, v_n\}\] where \(v_i\) are the columns of \(V\).

A.2.2 Steps to Identify the Null Space

  1. Compute the SVD: \(G = U \Sigma V^T\)
  2. Identify the rank \(r\) as the number of non-zero singular values
  3. Extract the right singular vectors \(v_{r+1}, \ldots, v_n\) corresponding to the zero singular values
  4. The null space basis is \(\text{null}(G) = \text{span}\{v_{r+1}, \ldots, v_n\}\)

A.3 Pseudoinverse and Min-Norm Solution

The Moore-Penrose pseudoinverse \(G^+\) is defined via SVD as: \[G^+ = V \Sigma^+ U^T\] where \(\Sigma^+\) is obtained by taking reciprocals of the non-zero singular values and transposing.

\(G^+\) simultaneously solves two optimality problems. When \(b \notin \text{col}(G)\) the system \(Ga = b\) is inconsistent, and \(G^+b\) is the least-squares solution minimizing \(\|Ga - b\|_2^2\). When the system is consistent but underdetermined, \(G^+b\) is the minimum-norm solution among all exact solutions.

For a system \(Ga = b\), the general solution is: \[a = G^+ b + \sum_{i=r+1}^{n} c_i v_i\] where the second term spans \(\text{null}(G)\). The norm of the general solution is: \[\|a\|^2 = \|G^+ b\|^2 + \sum_{i=r+1}^{n} c_i^2\] since \(G^+ b\) lies in the row space of \(G\), which is orthogonal to \(\text{null}(G)\). This is minimized by setting all \(c_i = 0\), giving the minimum-norm solution: \[a^* = G^+ b\]
