9  Estimating \(\kappa_{22}\) via \(V\)

9.0.1 Estimating \(\kappa_{22}\) via \(V_{xy}\)

Let \(s_i^{(k)} = (X_i - X_{i+k})(Y_i - Y_{i+k})\) and \(S_i = \frac{s_i^{(1)} + s_{i+1}^{(1)} - s_i^{(2)}}{2}\) as in the Multiplier Bootstrap chapter, so that \[ \boxed{\bar{S} = \frac{1}{n}\sum_{i=1}^n S_i = \frac{2T_1(X,Y) - T_2(X,Y)}{2n} = \hat\sigma_{xy}.} \] Since \(S_i\) depends only on indices \(i-2, i-1, i\), terms at lags \(\ge 3\) are independent, so \[ \operatorname{Var}(\bar{S}) = \frac{1}{n^2}\!\left[\sum_i \operatorname{Var}(S_i) + 2\sum_i \operatorname{Cov}(S_i, S_{i+1}) + 2\sum_i \operatorname{Cov}(S_i, S_{i+2})\right]. \] Replacing each population quantity with its sample analog gives the lag-2 variance estimate \[ V := \widehat{\operatorname{Var}}(\bar{S}) = \frac{1}{n^2}\!\left(\sum_{i=1}^n S_i^2 + \sum_{i=1}^n (S_i S_{i+1} + S_{i+1} S_i) + \sum_{i=1}^n (S_i S_{i+2} + S_{i+2} S_i)\right), \] or in matrix form, writing \(\mathbf{S} = (S_1, \ldots, S_n)^\top\), \[ \boxed{V = \frac{1}{n^2}\,\mathbf{S}^\top(I + C_1 + C_1^\top + C_2 + C_2^\top)\mathbf{S}.} \]

Since \(\bar S = (2T_1 - T_2)/(2n)\), we have \(V \approx \operatorname{Var}(2T_1 - T_2)/(4n^2)\). The variance on the right has a general closed form; under \(H_0\) (\(\sigma_{xy} = 0\)) it simplifies so we can solve for \(\kappa_{22}\) from \(V\).

Derivation: \(\operatorname{Var}(\bar{S})\) from \(\Sigma_Z\)

Since \(\bar{S} = (2T_1 - T_2)/(2n)\), \[ \operatorname{Var}(\bar{S}) = \frac{1}{4n^2}\bigl(4[\Sigma_Z]_{55} - 4[\Sigma_Z]_{56} + [\Sigma_Z]_{66}\bigr). \] The general \(\Sigma_Z\) entries from the Z-Test chapter are \[[\Sigma_Z]_{55} = 2n\sigma_x^2\sigma_y^2(2\kappa_{22}+1) - 2n\sigma_{xy}^2 + 2n\sigma_y^2\omega_x^2 + 2n\sigma_x^2\omega_y^2 + 4n\sigma_{xy}\omega_{xy},\] \[[\Sigma_Z]_{56} = 4n(\sigma_x^2\sigma_y^2\kappa_{22} - \sigma_{xy}^2) + 2n\sigma_y^2\omega_x^2 + 2n\sigma_x^2\omega_y^2 + 4n\sigma_{xy}\omega_{xy},\] \[[\Sigma_Z]_{66} = 2n\sigma_x^2\sigma_y^2(2\kappa_{22}+1) - 2n\sigma_{xy}^2 + 4n\sigma_y^2\omega_x^2 + 4n\sigma_x^2\omega_y^2 + 8n\sigma_{xy}\omega_{xy}.\] Substituting and collecting terms gives the general expression \[\operatorname{Var}(\bar{S}) = \frac{1}{2n}\bigl[(2\kappa_{22}+5)\sigma_x^2\sigma_y^2 + 3\sigma_{xy}^2 + 4\sigma_{xy}\omega_{xy} + 2\sigma_y^2\omega_x^2 + 2\sigma_x^2\omega_y^2\bigr].\] Under \(H_0\) (\(\sigma_{xy} = 0\)) the last two terms vanish, yielding \[\operatorname{Var}(\bar{S}) = \frac{1}{2n}\bigl[(2\kappa_{22}+5)\sigma_x^2\sigma_y^2 + 2\sigma_y^2\omega_x^2 + 2\sigma_x^2\omega_y^2\bigr]. \qquad\square\]

Since \(V \approx \operatorname{Var}(\bar{S})\), substituting the general expression and solving gives \[\boxed{\hat\kappa_{22} = \frac{nV}{\hat\sigma_x^2\hat\sigma_y^2} - \frac{3}{2}\frac{\hat\sigma_{xy}^2}{\hat\sigma_x^2\hat\sigma_y^2} - \frac{2\hat\sigma_{xy}\hat\omega_{xy}}{\hat\sigma_x^2\hat\sigma_y^2} - \frac{\hat\omega_x^2}{\hat\sigma_x^2} - \frac{\hat\omega_y^2}{\hat\sigma_y^2} - \frac{5}{2}.}\] Under \(H_0\) (\(\hat\sigma_{xy} = 0\)) the middle two terms vanish, yielding \[\hat\kappa_{22} = \frac{nV}{\hat\sigma_x^2\hat\sigma_y^2} - \frac{\hat\omega_x^2}{\hat\sigma_x^2} - \frac{\hat\omega_y^2}{\hat\sigma_y^2} - \frac{5}{2}.\]

Simulation: Verifying \(\hat\kappa_{22}\) via \(V_{xy}\)
  • Independent (\(\kappa_{22} = 1\))
  • Dependent (\(\kappa_{22} = 5\))
  • \(\lambda\)-Mixing

Scenario 2, \(L = 4\), Gaussian independent errors. Under independence \(\kappa_{22} = 1\) regardless of marginals.

Using \(\varepsilon_y = (\varepsilon_x^2 - 1)/\sqrt{2}\) with \(\varepsilon_x \sim N(0,1)\), giving \(\sigma_{xy} = 0\) and \(\kappa_{22} = 5\).

Using \(\varepsilon_y = \lambda(\varepsilon_x^2-1)/\sqrt{2} + \sqrt{1-\lambda^2}\,\eta\) with \(\varepsilon_x, \eta \stackrel{iid}{\sim} N(0,1)\), which gives \(\sigma_{xy} = 0\) and \(\kappa_{22} = 1 + 4\lambda^2\).

9.0.2 Estimating \(\kappa_{40}\) via \(V_{xx}\)

Applying the same construction to \((X, X)\) in place of \((X, Y)\): let \(s_i^{(k)} = (X_i - X_{i+k})^2\) and \(S_i^{xx} = (s_i^{(1)} + s_{i+1}^{(1)} - s_i^{(2)})/2\), so that \(\bar S^{xx} = (2T_1(X,X) - T_2(X,X))/(2n) = \hat\sigma_x^2\). Define \[ V_{xx} := \widehat{\operatorname{Var}}(\bar S^{xx}) = \frac{1}{n^2}\,(\tilde{\mathbf{S}}^{xx})^\top(I + C_1 + C_1^\top + C_2 + C_2^\top)\tilde{\mathbf{S}}^{xx}, \qquad \tilde S_i^{xx} = S_i^{xx} - \bar S^{xx}. \]

Derivation: \(\operatorname{Var}(\bar{S}^{xx})\) from \(\Sigma_Z\)

Since \(\bar{S}^{xx} = (2T_1(X,X) - T_2(X,X))/(2n)\), \[ \operatorname{Var}(\bar{S}^{xx}) = \frac{1}{4n^2}\bigl(4[\Sigma_Z]_{11} - 4[\Sigma_Z]_{12} + [\Sigma_Z]_{22}\bigr). \] Substituting the entries from the Z-Test chapter: \[[\Sigma_Z]_{11} = 4n\kappa_{40}\sigma_x^4 + 8n\sigma_x^2\omega_x^2,\] \[[\Sigma_Z]_{12} = 4n(\kappa_{40}-1)\sigma_x^4 + 8n\sigma_x^2\omega_x^2,\] \[[\Sigma_Z]_{22} = 4n\kappa_{40}\sigma_x^4 + 16n\sigma_x^2\omega_x^2.\] Collecting terms: \[\operatorname{Var}(\bar{S}^{xx}) = \frac{1}{n}\bigl[(\kappa_{40}+4)\sigma_x^4 + 4\sigma_x^2\omega_x^2\bigr]. \qquad\square\]

Since \(V_{xx} \approx \operatorname{Var}(\bar{S}^{xx})\), substituting and solving gives \[ \boxed{\hat\kappa_{40} = \frac{nV_{xx}}{\hat\sigma_x^4} - \frac{4\hat\omega_x^2}{\hat\sigma_x^2} - 4.} \] By symmetry (\(x \leftrightarrow y\)), the same construction applied to \((Y, Y)\) yields \(\hat\kappa_{04} = nV_{yy}/\hat\sigma_y^4 - 4\hat\omega_y^2/\hat\sigma_y^2 - 4\).

Simulation: Verifying \(\hat\kappa_{40}\)
  • Gaussian (\(\kappa_{40} = 3\))
  • Exponential (\(\kappa_{40} = 9\))
  • \(\lambda\)-Mixing

Scenario 2, \(L = 4\), Gaussian errors (\(\kappa_{40} = 3\)).

Scenario 2, \(L = 4\), exponential errors (\(\kappa_{40} = 9\)).

Using \(\varepsilon_x = \lambda(z^2-1)/\sqrt{2} + \sqrt{1-\lambda^2}\,w\) with \(z, w \stackrel{iid}{\sim} N(0,1)\), which gives \(\kappa_{40} = 12\lambda^4 + 3\).

9.0.3 Estimating \(\kappa_{31}\) via \(C_{xx,xy}\)

The cumulant \(\kappa_{31}\) appears in the cross-covariances between the \((X,X)\) and \((X,Y)\) blocks of \(\Sigma_Z\). Define the lag-2 cross-covariance \[ C_{xx,xy} := \frac{1}{n^2}\,(\tilde{\mathbf{S}}^{xx})^\top(I + C_1 + C_1^\top + C_2 + C_2^\top)\tilde{\mathbf{S}}^{xy}, \qquad \tilde S_i^{xx} = S_i^{xx} - \bar S^{xx},\quad \tilde S_i^{xy} = S_i^{xy} - \bar S^{xy}, \] which estimates \(\operatorname{Cov}(\bar S^{xx}, \bar S^{xy})\).

Derivation: \(\operatorname{Cov}(\bar{S}^{xx}, \bar{S}^{xy})\) from \(\Sigma_Z\)

Since \(\bar{S}^{xx} = (2T_1(X,X) - T_2(X,X))/(2n)\) and \(\bar{S}^{xy} = (2T_1(X,Y) - T_2(X,Y))/(2n)\), \[ \operatorname{Cov}(\bar{S}^{xx}, \bar{S}^{xy}) = \frac{1}{4n^2}\bigl(4[\Sigma_Z]_{15} - 2[\Sigma_Z]_{16} - 2[\Sigma_Z]_{25} + [\Sigma_Z]_{26}\bigr). \] The relevant entries from the Z-Test chapter are \[[\Sigma_Z]_{15} = 4n\sigma_x^3\sigma_y\kappa_{31} + 4n\sigma_{xy}\omega_x^2 + 4n\sigma_x^2\omega_{xy},\] \[[\Sigma_Z]_{16} = 4n\sigma_x^3\sigma_y\kappa_{31} - 4n\sigma_x^2\sigma_{xy} + 4n\sigma_{xy}\omega_x^2 + 4n\sigma_x^2\omega_{xy},\] \[[\Sigma_Z]_{25} = 4n\sigma_x^3\sigma_y\kappa_{31} - 4n\sigma_x^2\sigma_{xy} + 4n\sigma_{xy}\omega_x^2 + 4n\sigma_x^2\omega_{xy},\] \[[\Sigma_Z]_{26} = 4n\sigma_x^3\sigma_y\kappa_{31} + 8n\sigma_{xy}\omega_x^2 + 8n\sigma_x^2\omega_{xy}.\] Collecting terms: \[\operatorname{Cov}(\bar{S}^{xx}, \bar{S}^{xy}) = \frac{1}{n}\bigl[\sigma_x^3\sigma_y\kappa_{31} + 4\sigma_x^2\sigma_{xy} + 2\sigma_{xy}\omega_x^2 + 2\sigma_x^2\omega_{xy}\bigr]. \qquad\square\]

Since \(C_{xx,xy} \approx \operatorname{Cov}(\bar{S}^{xx}, \bar{S}^{xy})\), substituting and solving gives \[ \hat\kappa_{31} = \frac{nC_{xx,xy}}{\hat\sigma_x^3\hat\sigma_y} - \frac{4\hat\sigma_{xy}}{\hat\sigma_x\hat\sigma_y} - \frac{2\hat\sigma_{xy}\hat\omega_x^2}{\hat\sigma_x^3\hat\sigma_y} - \frac{2\hat\omega_{xy}}{\hat\sigma_x\hat\sigma_y}. \] By symmetry (\(x \leftrightarrow y\)), the same construction with \(C_{yy,xy}\) yields \(\hat\kappa_{13}\).

Simulation: Verifying \(\hat\kappa_{31}\)
  • Independent (\(\kappa_{31} = 0\))
  • Dependent (\(\kappa_{31} = 3\))
  • \(\lambda\)-Mixing

Scenario 2, \(L = 4\), Gaussian independent errors. Under independence \(\kappa_{31} = 0\).

Using \(\varepsilon_y = \varepsilon_x\) with \(\varepsilon_x \sim N(0,1)\), giving \(\sigma_{xy} = \sigma_x^2\) and \(\kappa_{31} = \kappa_{40} = 3\).

Using \(\varepsilon_y = \lambda\varepsilon_x + \sqrt{1-\lambda^2}\,\eta\) with \(\varepsilon_x, \eta \stackrel{iid}{\sim} N(0,1)\), which gives \(\kappa_{31} = 3\lambda\).
