6  Z-Test

Theorem: Asymptotic Distribution of \(\hat\rho\)

If \(\max_j\{(\mu_{x,j} - \mu_{x,j+1})^2\} = o(n)\), \(\max_j\{(\mu_{y,j} - \mu_{y,j+1})^2\} = o(n)\), and the errors have finite 4th moments, then the ECE correlation estimator satisfies \[ \sqrt{n}(\hat\rho - \rho) \xrightarrow{d} N(0,\, v^2). \] Since \(\hat\rho\) is scale-invariant, we may take \(\sigma_x = \sigma_y = 1\) without loss of generality, giving \[ v^2 = \frac{1}{n}\left[ (1-\rho^2)\!\left(\omega_x^2 + \omega_y^2 - 2\rho\,\omega_{xy}\right) + \frac{\rho^2}{4}(\kappa_{40} + 2\kappa_{22} + \kappa_{04}) - \rho(\kappa_{31} + \kappa_{13}) + \kappa_{22} + \frac{5}{2}(1-\rho^2)^2 \right]. \]

Remark: Asymptotic Variance Under Gaussian Errors

Under the Gaussian assumption (\(\kappa_{40} = \kappa_{04} = 3\), \(\kappa_{31} = \kappa_{13} = 3\rho\), \(\kappa_{22} = 1 + 2\rho^2\)), \(v^2\) reduces to \[ v^2 = \frac{1}{n}(1-\rho^2)\!\left(\omega_x^2 + \omega_y^2 - 2\rho\,\omega_{xy} + \frac{7}{2}(1-\rho^2)\right). \]

Remark: Asymptotic Variance for \(\rho = 0\) Under Gaussian Errors

Setting \(\rho = 0\) under the Gaussian assumption (\(\kappa_{22} = 1\)), \[ v^2 = \frac{1}{n}\!\left(\omega_x^2 + \omega_y^2 + \frac{7}{2}\right). \]

Remark: Asymptotic Variance for \(\rho = 0\)

Setting \(\rho = 0\) in the general formula, \[ v^2 = \frac{1}{n}\!\left(\omega_x^2 + \omega_y^2 + \kappa_{22} + \frac{5}{2}\right). \]

Define the lag-\(k\) cross-product statistic \(T_k(X, Y) = \sum_{i=1}^{n} (X_i - X_{i+k})(Y_i - Y_{i+k})\), and let \[ Z = \begin{pmatrix} Z_1 \\ Z_2 \\ Z_3 \\ Z_4 \\ Z_5 \\ Z_6 \end{pmatrix} = \begin{pmatrix} T_1(X,X) \\ T_2(X,X) \\ T_1(Y,Y) \\ T_2(Y,Y) \\ T_1(X,Y) \\ T_2(X,Y) \end{pmatrix}. \]

The proof applies the Multivariate Delta Method in three steps:

Step 1. Show that \[ \frac{1}{\sqrt{n}}(Z - \mu_Z) \xrightarrow{d} N(\mathbf{0}, \Sigma_Z), \quad \mu_Z = \mathbb{E}[Z]. \]

Proposition: Asymptotic Normality of \(Z\)

Under the model assumptions, if \(\max_j\{(\mu_{x,j} - \mu_{x,j+1})^2\} = o(n)\) and \(\max_j\{(\mu_{y,j} - \mu_{y,j+1})^2\} = o(n)\), and errors have finite 4th moments, then \[ \frac{1}{\sqrt{n}}(Z - \mathbb{E}[Z]) \xrightarrow{d} N(\mathbf{0}, \Sigma_Z). \]

Proof: Asymptotic Normality of \(Z\)

Strategy. Each component of \(Z\) is of the form \(T_k(X,Y)\) for some lag \(k\) and choice of series. It therefore suffices to show \(T_k(X,Y)\) is asymptotically normal, since any linear combination \(a^T Z\) inherits this structure. The Cramér-Wold device then promotes univariate normality to joint normality of the full vector.

By the Cramér-Wold device, it suffices to show every linear combination \(a^T Z\) is asymptotically normal. We handle the general cross-product component \(T_k(X,Y)\); the diagonal components \(T_k(X,X)\) and \(T_k(Y,Y)\) follow as special cases.

Substituting \(X_i = \theta_{x,i} + \varepsilon_{x,i}\) and \(Y_i = \theta_{y,i} + \varepsilon_{y,i}\) and expanding gives four terms:

\[\begin{align} T_k(X,Y) &= \sum_{i=1}^n (\theta_{x,i} - \theta_{x,i+k})(\theta_{y,i} - \theta_{y,i+k}) \\ &\quad + \sum_{i=1}^n (\theta_{x,i} - \theta_{x,i+k})(\varepsilon_{y,i} - \varepsilon_{y,i+k}) + \sum_{i=1}^n (\theta_{y,i} - \theta_{y,i+k})(\varepsilon_{x,i} - \varepsilon_{x,i+k}) \\ &\quad + \sum_{i=1}^n (\varepsilon_{x,i} - \varepsilon_{x,i+k})(\varepsilon_{y,i} - \varepsilon_{y,i+k}). \end{align}\]

The first term equals \(kW_{xy}\) and is deterministic. The last term has expectation \(2n\sigma_{xy}\), so adding and subtracting this expectation gives

\[\begin{align} T_k(X,Y) &= \underbrace{kW_{xy} + 2n\sigma_{xy}}_{\mathbb{E}[T_k(X,Y)]} \\ &\quad + \underbrace{\sum_{i=1}^n (\theta_{x,i} - \theta_{x,i+k})(\varepsilon_{y,i} - \varepsilon_{y,i+k}) + \sum_{i=1}^n (\theta_{y,i} - \theta_{y,i+k})(\varepsilon_{x,i} - \varepsilon_{x,i+k})}_{\text{(I) mixed}} \\ &\quad + \underbrace{\sum_{i=1}^n \bigl[(\varepsilon_{x,i} - \varepsilon_{x,i+k})(\varepsilon_{y,i} - \varepsilon_{y,i+k}) - 2\sigma_{xy}\bigr]}_{\text{(II) purely random}}, \end{align}\]

where \(W_{xy} = T_1(\theta_x, \theta_y)\).

Term (II) is a sum of mean-zero, \(k\)-dependent, identically distributed random variables (since errors are i.i.d.), so the CLT for \(m\)-dependent sequences applies directly.

Term (I). Consider the first sum; the second is identical in structure with \(x\) and \(y\) exchanged. Splitting the error differences, \[ \sum_{i=1}^n (\theta_{x,i} - \theta_{x,i+k})(\varepsilon_{y,i} - \varepsilon_{y,i+k}) = \sum_{i=1}^n (\theta_{x,i} - \theta_{x,i+k})\varepsilon_{y,i} - \sum_{i=1}^n (\theta_{x,i} - \theta_{x,i+k})\varepsilon_{y,i+k}, \] each of which is a weighted sum of independent errors with deterministic coefficients \(c_i = \theta_{x,i} - \theta_{x,i+k}\). Since \(\theta_x\) is piecewise constant, the nonzero coefficients take values \(\{\mu_{x,j} - \mu_{x,j+1}\}\), giving \(\sum_i c_i^2 = kW_x(\theta)\) and \(\max_i c_i^2 = \max_j (\mu_{x,j} - \mu_{x,j+1})^2\).

The proposition condition \(\max_j\{(\mu_{x,j} - \mu_{x,j+1})^2\} = o(n)\) implies one of two cases:

Case 1: \(W_x(\theta) = o(n)\). Then Term (I) has standard deviation \(O(\sqrt{W_x(\theta)}) = o(\sqrt{n})\), so Term (I)\(/\sqrt{n} \xrightarrow{p} 0\). By Slutsky’s theorem, \([{\rm Term\;(I)} + {\rm Term\;(II)}]/\sqrt{n}\) has the same limiting distribution as Term (II)\(/\sqrt{n}\), which is normal by the CLT for \(m\)-dependent sequences.

Case 2: \(W_x(\theta) = \Omega(n)\). Since \(\max_j(\mu_{x,j} - \mu_{x,j+1})^2 = o(n)\) and \(W_x(\theta) = \Omega(n)\), we have \[ \frac{\max_j (\mu_{x,j} - \mu_{x,j+1})^2}{W_x(\theta)} \to 0, \] which is equivalent to \(\max_i c_i^2 / \sum_i c_i^2 \to 0\). This is the Lindeberg condition for the weighted sum \(\sum_i c_i \varepsilon_{y,i}\), which ensures it is asymptotically normal. Term (I) is therefore asymptotically normal, and together with Term (II), the sum is asymptotically normal.

Since any linear combination \(a^T Z\) is a sum of terms of the form (I) and (II) across components and lags, the same argument applies in both cases, and the Cramér-Wold device gives joint normality of \(Z\). \(\square\)

Step 3. Define \[ g(Z) = \frac{2Z_5 - Z_6}{\sqrt{(2Z_1 - Z_2)(2Z_3 - Z_4)}} = \hat\rho. \] Since \(g(\mu_Z) = \rho\), the multivariate delta method gives \[ \sqrt{n}(\hat\rho - \rho) \xrightarrow{d} N(0,\, v^2), \quad v^2 = \nabla g(\mu_Z)^\top \Sigma_Z\, \nabla g(\mu_Z). \]

Gradient: \(\nabla g(\mu_Z)\)

The gradient of \(g\) evaluated at \(\boldsymbol{\mu}_Z\) is

\[ \nabla g(\boldsymbol{\mu}_Z) = \begin{pmatrix} -\dfrac{g(\mathbf{Z})}{2Z_1 - Z_2} \\[6pt] \dfrac{1}{2}\dfrac{g(\mathbf{Z})}{2Z_1 - Z_2} \\[6pt] -\dfrac{g(\mathbf{Z})}{2Z_3 - Z_4} \\[6pt] \dfrac{1}{2}\dfrac{g(\mathbf{Z})}{2Z_3 - Z_4} \\[6pt] \dfrac{2}{\sqrt{(2Z_1-Z_2)(2Z_3-Z_4)}} \\[6pt] -\dfrac{1}{\sqrt{(2Z_1-Z_2)(2Z_3-Z_4)}} \end{pmatrix}_{\mathbf{Z} = \boldsymbol{\mu}_Z} = \frac{1}{2n} \begin{pmatrix} -\rho/\sigma_x^2 \\ \rho/(2\sigma_x^2) \\ -\rho/\sigma_y^2 \\ \rho/(2\sigma_y^2) \\ 2/(\sigma_x\sigma_y) \\ -1/(\sigma_x\sigma_y) \end{pmatrix}, \]

using \(2\mu_{Z_1} - \mu_{Z_2} = 2n\sigma_x^2\), \(2\mu_{Z_3} - \mu_{Z_4} = 2n\sigma_y^2\), \(2\mu_{Z_5} - \mu_{Z_6} = 2n\sigma_{xy}\), and \(g(\boldsymbol{\mu}_Z) = \rho\).

6.1 Diagnostics

Test: \(Var(\hat{\rho})\) is Scale-Invariant

We can define the asymptotic variance of \(\hat{\rho}\) as \[ v^2 = \frac{1}{n}\left[ (1-\rho^2)\!\left(\frac{\omega_x^2}{\sigma_x^2} + \frac{\omega_y^2}{\sigma_y^2} - \frac{2\rho\,\omega_{xy}}{\sigma_x\sigma_y}\right) + \frac{\rho^2}{4}(\kappa_{40} + 2\kappa_{22} + \kappa_{04}) - \rho(\kappa_{31} + \kappa_{13}) + \kappa_{22} + \frac{5}{2}(1-\rho^2)^2 \right]. \]

Since \(\widehat\rho(aX, bY) = \widehat\rho(X, Y)\) for any \(a, b > 0\), the asymptotic variance \(v^2\) must be invariant under \(X \to aX\), \(Y \to bY\). We verify this term by term.

\(\omega\) terms. Scaling \(X\) by \(a\) sends \(\theta_x \to a\theta_x\), so \(\omega_x^2 \to a^2\omega_x^2\) and \(\sigma_x \to a\sigma_x\). Similarly \(\omega_y \to b\omega_y\), \(\omega_{xy} \to ab\,\omega_{xy}\). The ratios \[ \frac{\omega_x^2}{\sigma_x^2} \to \frac{a^2\omega_x^2}{a^2\sigma_x^2} = \frac{\omega_x^2}{\sigma_x^2}, \qquad \frac{\rho\,\omega_{xy}}{\sigma_x\sigma_y} \to \frac{\rho\cdot ab\,\omega_{xy}}{a\sigma_x\cdot b\sigma_y} = \frac{\rho\,\omega_{xy}}{\sigma_x\sigma_y} \] are unchanged.

\(\kappa\) terms. The \(\kappa_{rs}\) are cumulants of the standardized errors \(\varepsilon_x/\sigma_x\) and \(\varepsilon_y/\sigma_y\). Scaling \(X\) by \(a\) scales both \(\varepsilon_x\) and \(\sigma_x\) by \(a\), leaving the ratio unchanged, so all \(\kappa_{rs}\) are invariant. \(\rho\) is invariant by definition.

Therefore \(v^2\) is scale-invariant, and we may study \(X/\sigma_x\), \(Y/\sigma_y\) in place of \(X\), \(Y\) without loss of generality. Setting \(\sigma_x = \sigma_y = 1\):

\[ v^2 = \frac{1}{n}\left[ (1-\rho^2)\!\left(\omega_x^2 + \omega_y^2 - 2\rho\,\omega_{xy}\right) + \frac{\rho^2}{4}(\kappa_{40} + 2\kappa_{22} + \kappa_{04}) - \rho(\kappa_{31} + \kappa_{13}) + \kappa_{22} + \frac{5}{2}(1-\rho^2)^2 \right]. \]

6.2 Variance Difference: General vs. Gaussian

Recall the asymptotic variance under the general and Gaussian assumptions: \[ V = \frac{1}{n}\left[(1-\rho^2)\!\left(\frac{\omega_x^2}{\sigma_x^2} + \frac{\omega_y^2}{\sigma_y^2} - \frac{2\rho\,\omega_{xy}}{\sigma_x\sigma_y}\right) + \frac{\rho^2}{4}(\kappa_{40}+2\kappa_{22}+\kappa_{04}) - \rho(\kappa_{31}+\kappa_{13}) + \frac{5}{2}(1-\rho^2)^2 + \kappa_{22}\right], \] \[ V_G = \frac{1}{n}(1-\rho^2)\!\left(\frac{\omega_x^2}{\sigma_x^2} + \frac{\omega_y^2}{\sigma_y^2} - \frac{2\rho\,\omega_{xy}}{\sigma_x\sigma_y} + \frac{7}{2}(1-\rho^2)\right). \] The jump-noise terms cancel, giving \[ V - V_G = \frac{1}{n}\left[\frac{\rho^2}{4}(\kappa_{40}+2\kappa_{22}+\kappa_{04}) - \rho(\kappa_{31}+\kappa_{13}) + \kappa_{22} - (1-\rho^2)^2\right]. \] This is zero under the Gaussian assumption and measures the excess variance due to non-Gaussianity.

params <- scenario(2, n = 1000, L = 4, r = 0.3, err_type = "exponential")

n   <- params$n
sx  <- sqrt(params$S[1, 1])
sy  <- sqrt(params$S[2, 2])
sxy <- params$S[1, 2]
rho <- sxy / (sx * sy)
hx  <- params$h[, 1]
hy  <- params$h[, 2]
k   <- params$kappa

omega <- (1 - rho^2) * (
  lag_diff(hx) / (n * sx^2) +
  lag_diff(hy) / (n * sy^2) -
  2 * rho * lag_diff(hx, hy) / (n * sx * sy)
)

V_general <- (1/n) * (
  omega +
  rho^2/4 * (k$k40 + 2*k$k22 + k$k04) - rho*(k$k31 + k$k13) +
  5/2 * (1 - rho^2)^2 + k$k22
)
V_gaussian <- (1/n) * (omega + 7/2 * (1 - rho^2)^2)

data.frame(
  V_diff_direct  = V_general - V_gaussian,
  V_diff_formula = (1/n) * (
    rho^2/4 * (k$k40 + 2*k$k22 + k$k04) - rho*(k$k31 + k$k13) +
    k$k22 - (1 - rho^2)^2
  )
