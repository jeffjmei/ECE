11  Power

11.1 Summary

  • Overall ranking (\(p = 2\)): Z-Test (Gaussian) > Z-Test (Oracle \(\kappa_{22}\)) \(\approx\) Z-Test (Gaussian) > Z-Test (Null) \(\approx\) Bootstrap (Parametric) > Bootstrap (Multiplier)
  • Gaussian assumption vs oracle \(\kappa_{22}\): little difference in power; the Gaussian SE is nearly as good as knowing the true \(\kappa_{22}\)
  • Wald vs score: Z-Test (Gaussian) outperforms Z-Test (Null, Gaussian) because estimating \(\hat{\rho}\) in the SE (Wald-type) is more efficient than plugging in \(\rho = 0\) (score-type)
  • Shared variance estimator: Z-Test (Null) and Bootstrap (Parametric) track each other closely, as both rely on \(\widehat{\text{Cov}}(S)\)
  • \(p > 2\): only bootstrap methods available; Bootstrap (Parametric) dominates Bootstrap (Multiplier)

11.2 \(p = 2\)

The Gaussian z-test is nearly as powerful as knowing the true κ₂₂

\(n = 200\), \(p = 2\).

  • Normal errors: Z-Test (Gaussian) and Z-Test (Oracle κ₂₂) are indistinguishable
  • Exponential errors: Z-Test (Oracle κ₂₂) has a slight power advantage over Z-Test (Gaussian)
  • normal
  • exponential

Z-Test (Gaussian) is more powerful than bootstrap methods, regardless of error distribution

\(n = 200\), \(p = 2\).

  • Power ranking: Z-Test (Gaussian) > Bootstrap (Parametric) > Bootstrap (Multiplier)
  • Error distribution: power curves are similar across normal and exponential errors
  • normal
  • exponential

Z-Test (Null) is less powerful than Z-Test (Null, Gaussian) because κ₂₂ must be estimated

\(n = 200\), \(p = 2\).

  • Z-Test (Null, Gaussian) assumes Gaussian errors and avoids estimating \(\kappa_{22}\)
  • Z-Test (Null) estimates \(\kappa_{22}\) from data, incurring a power cost
  • normal
  • exponential

Z-Test (Gaussian) is more powerful than Z-Test (Null, Gaussian): estimating ρ improves the SE

\(n = 200\), \(p = 2\).

  • Z-Test (Gaussian) uses the unrestricted SE — the denominator includes \(\hat{\rho}\)
  • Z-Test (Null, Gaussian) plugs in \(\rho = 0\) under \(H_0\), giving a less efficient SE
  • This mirrors classical theory: the Wald statistic (unrestricted SE) is generally more powerful than the score statistic (null SE) at alternatives away from zero
  • normal
  • exponential

Z-Test (Null) and Bootstrap (Parametric) have nearly identical power

\(n = 200\), \(p = 2\).

  • The two methods have similar power across scenarios and error distributions
  • This is unsurprising: the Z-Test (Null) estimates \(\kappa_{22}\) via \(\widehat{\text{Cov}}(S)\), which is the same quantity the parametric bootstrap variance estimate is based on
  • normal
  • exponential

11.3 \(p > 2\)

Bootstrap (Parametric) outperforms Bootstrap (Multiplier) at p = 3; higher dimensions unavailable

\(n = 200\), \(p \in \{3, 5, 10\}\).

  • p = 3: Bootstrap (Parametric) is more powerful than Bootstrap (Multiplier)
  • p = 5, 10: no results — the estimated covariance matrix \(\hat{W}\) is sometimes not positive semi-definite, causing simulation errors
  • normal
  • exponential

Parametric bootstrap power is recovered with PSD eigenvalue correction

\(\widehat{\text{Cov}}(S)\) may not always produce a PSD covariance matrix; consequently, we cannot sample from a non-PSD covariance matrix. The eigenvalue correction clips any negative eigenvalues of \(\hat{W}\) to zero before sampling.

  • Low (~6–7% failure)
  • Moderate (~30% failure)
  • Extreme (100% failure)

Under normal errors with \(n = 500\), roughly 6–7% of replicates produce a non-PSD \(\hat{W}\). The corrected curve is nearly indistinguishable from the uncorrected — the correction is harmless at low failure rates.

Under exponential errors with \(n = 500\), roughly 30% of replicates produce a non-PSD \(\hat{W}\). Even at this failure rate, the corrected curve continues to track the uncorrected closely — the correction is robust.

Under exponential errors with \(n = 200\), every replicate fails to produce a PSD \(\hat{W}\) — no uncorrected curve exists. The corrected curve is the only available estimate. The Type I error is deflated rather than inflated — conservative behavior, which is preferable to anti-conservative.

Parametric Bootstrap power is nearly identical to Z-Test (Null)

11.4 Parametric Bootstrap vs Z-Test (Null)

When correlation is non-trivial, bs.parametric and z.test.null track each other closely. Both methods rely on \(\widehat{\text{Cov}}(S)\): the parametric bootstrap uses it to characterize the sampling distribution, while Z-Test (Null) uses it to estimate \(\kappa_{22}\).
